# D3wa دعوة — Digital Invitation Studio

Elegant bilingual (Arabic/English) digital invitations for weddings, engagements, katb kitab and sebou3 — made in Egypt. 🤍

Each invitation is a fast, static, mobile-first page with a live countdown, one-tap WhatsApp RSVP, venue map, add-to-calendar and instant AR/EN switching.

## Structure

- `index.html` — storefront (collection, founder note, prices, FAQ)
- `order.html` — five-step order builder with live preview
- `demos/` — the 12 live templates: gold, rose, rustic, navy, emerald, sahara, henna, deco, garden, modern, lotus, grad
- `assets/cards/` — one screenshot per template, generated by `node scripts/shots.mjs` (rerun after editing a template)
- `assets/og/` — WhatsApp / social preview images
- `scripts/set-domain.sh` — rewrites absolute URLs when the domain changes
- `worker/` — Cloudflare Worker + D1 order backend (see `worker/README.md`)

No build step. Pure HTML/CSS/JS, Google Fonts only.

## Hosting
