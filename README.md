# D3wa دعوة — Digital Invitation Studio

Elegant bilingual (Arabic/English) digital invitations for weddings, engagements, katb kitab and sebou3 — made in Egypt. 🤍

Each invitation is a fast, static, mobile-first page with a live countdown, one-tap WhatsApp RSVP, venue map, add-to-calendar and instant AR/EN switching.

## Structure

- `index.html` — storefront (templates, pricing, FAQ)
- `demos/` — live template demos:
  - `gold.html` — Classic Gold
  - `rose.html` — Rose & White
  - `rustic.html` — Rustic Red
  - `navy.html` — Royal Navy (dark + light mode)
  - `emerald.html` — Emerald Andalusi
  - `sahara.html` — Sahara Boho
  - `lotus.html` — Lotus Sebou3 (baby celebrations)

No build step. Pure HTML/CSS/JS, Google Fonts only.

## Hosting

Currently on GitHub Pages. Migration path: Cloudflare Pages (free tier) + custom domain via Cloudflare Registrar; client sites get subdomains.
